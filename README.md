# Temperature-Converter-Using-Functions-In-C-
This is a console based application using functions, conditional statements, and looping structures. With the help of these core concepts of C++ I have made a functional application.The program is a menu-driven temperature converter built in C++ using separate functions for each conversion type. It allows the user to convert temperatures between Celsius, Fahrenheit, and Kelvin through a clean and interactive interface. The program uses a switch–case structure to handle user choices and applies standard mathematical formulas inside dedicated conversion functions. The screen is cleared on each cycle to provide a better user experience, and results are displayed with two-decimal precision for accuracy. A loop enables the user to perform multiple conversions until they choose to exit the system.
